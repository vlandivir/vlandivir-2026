# Threads News

Закрытая страница `/threads-news` (также `/threads-news/en`) доступна только
Google admin. Переход — из композера `/threads`. HTML, ресурсы страницы и API
обслуживаются контроллерами с AdminSessionGuard; публичного static mount нет.

## Что работает

- Добавление по @username или HTTPS-ссылке на профиль Threads (.net/.com).
- Рекомендации личных блогов: Ethan Mollick (ИИ), Gergely Orosz
  (разработка), @olja_srbija (жизнь в Сербии), Nomadic Matt (путешествия).
  Добавление по одному, без автоматического seed.
- Темы, пауза/возобновление, ручное обновление одного автора или всех активных.
- Удаление автора удаляет и все собранные публикации этого автора.
- Лента сохранённых постов с фильтром автора и пагинацией по 30 постов.
- Очередь неоценённых постов: «интересно» / «неинтересно» кнопками, стрелками
  клавиатуры или горизонтальным свайпом; последнюю оценку можно отменить.
  В архиве оценки видны и исправляются, а список фильтруется по ним. Оценка
  сохраняется при повторной загрузке профиля и вместе с постом даёт выборку
  для будущего фильтра. Сейчас автоматическое скрытие не включено.
- Счётчики, последние попытки/успехи, число новых постов, ошибки.
- Открытые текстовые посты автоматически проверяются на язык и переводятся
  на русский через `OPENAI_MODELS.economical`. Оригинал всегда показан первым;
  перевод сохраняется в БД и повторно не оплачивается. Русские посты помечаются
  проверенными без второго текста. Лимит — 100 запросов в календарный месяц
  (UTC), длина поста для перевода — до 5000 символов. Запросы сверх лимита
  показывают сообщение, исходный текст остаётся доступен.

Сборщик использует анонимные веб GraphQL-запросы, проверенные в октябре 2026.
Токен Threads, cookies и аккаунт не нужны. ID веб-операций могут измениться;
неожиданная схема ответа показывается как ошибка, старые посты сохраняются.
За один запуск читается максимум три страницы по четыре ветки. Достижение
этого лимита — нормальная ограниченная выборка, а не ошибка; полная история
профиля не обещается. Вложенные цитаты других авторов не сохраняются. Посты
без текста остаются в ленте со ссылкой на оригинал; медиа не скачиваются.

Повторы временных сетевых ошибок и 429/5xx ограничены одной попыткой.
Обновление синхронное, с блокировкой источника в БД на время сбора. После
прерванной загрузки повтор разрешён через пять минут. Пауза исключает источник
из «Обновить все»; уже сохранённые публикации остаются доступными.

Автоматического расписания, обучения фильтра, проверки фактов, Telegram-команд и отправки
дайджестов в этом шаге нет. Перевод — единственный вызов ИИ. Темы — метки источника, не автоматическая
классификация каждого его поста.

## Выпуск и проверка

Перед выпуском кода применить additive-миграции
`20261022120000_threads_news` и `20261022170000_threads_news_feedback`
обычным `prisma migrate deploy` через DB tunnel.
Деплой остаётся ручным. Используется существующий `OPENAI_API_KEY`;
новых runtime env vars нет.

Unit/HTTP-проверки:
`npm test -- --runInBand threads-public-profile threads-news.controller`.

Интеграционные проверки сохранения включаются только с
`THREADS_NEWS_TEST_DATABASE_URL` на отдельную локальную базу
`postgresql://threads_news@127.0.0.1:55438/threads_news_test`, в которую
предварительно применён SQL обеих миграций Threads News. Тесты очищают только эти отдельные
таблицы в этой тестовой базе; адрес production ими не принимается.
Запуск: `npm test -- --runInBand threads-news.service`.

Ручная проверка: добавить автора, убедиться в загрузке; обновить ещё раз —
повторные ID не должны увеличивать число постов; проверить фильтр, темы,
паузу, недоступный профиль и сохранение состояния после перезапуска.
